# AI Usage Report

## 1. AI Tool Used

ChatGPT was used as an AI-assisted development and learning tool during the development of EduSupport.

## 2. Areas Where AI Was Used

AI assistance was used for:

- Understanding the assignment requirements
- Brainstorming product features
- Designing the ticket workflow
- Designing the database schema
- Generating Flask implementation suggestions
- Developing HTML templates
- Improving Bootstrap-based UI
- Debugging Python and Flask errors
- Suggesting test cases
- Preparing project documentation
- Preparing interview explanations

## 3. Human Validation

AI-generated suggestions were not treated as automatically correct.

The implementation was manually:

- Reviewed
- Added to the project
- Executed locally
- Tested through the browser
- Debugged when errors occurred
- Modified according to project requirements

## 4. Example of AI-Assisted Debugging

During development, a Flask `NameError` occurred because the `staff_users` variable was referenced in the template rendering without being defined in the route.

The issue was identified from the traceback and corrected by retrieving staff users from the database before closing the database connection.

## 5. AI-Assisted Product Decisions

AI was also used to explore product improvements such as:

- SLA tracking
- Ticket history
- Ticket reopening
- Role-based workflows
- Staff assignment
- Dashboard statistics

These suggestions were evaluated against the assignment requirements before implementation.

## 6. Limitations

AI assistance can produce incorrect or incomplete code.

Therefore, all generated code was tested locally and corrected when necessary.

## 7. Final Responsibility

The candidate is responsible for understanding, reviewing, testing and explaining the submitted implementation.
